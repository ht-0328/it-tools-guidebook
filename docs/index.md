## この文書は何か

**このリポジトリに収録しているツールの一覧である。** ツール1件ごとの説明は、下の表からたどる先にある。

## ツールを1件追加する手順

1. [ツール説明のテンプレート](../templates/tool.md) を `docs/<ツール名>.md` に写す
2. 冒頭のメタ情報の表を埋める
3. 本文を書く。丸かっこの例文と、書き方を指示する引用行は消す
4. この文書の「収録しているツール」の表に1行足し、「分類」の表の収録数を1つ増やす
5. `bash tools/doclint.sh` を実行し、`error: 0` であることを確認する

**書き始める前に [ドキュメント標準](../standards/engineering-docs-standard/docs/index.md) を読む。** 標準に従っていない文書は、検査を通っても受け入れない。
