# 突き合わせ結果の型

この型を `research/<YYYY-MM-DD>-<テーマ>/verdict.md` に写して埋める。
丸かっこの例文と、書き方を指示する引用行は消す。

## 目次

| 節 | 何を書くか |
|---|---|
| 突き合わせの概要 | 問い、投げた道具、回収できた数、日付 |
| 判定 | 主張1件ごとの結論と、確定・暫定・未確認の別 |
| 主張別の突き合わせ表 | 3つの道具の答えを横に並べた表 |
| 差し戻しの記録 | 投げ直した争点と、返ってきた変化 |
| 残った穴 | どの道具も埋められなかった問い |
| 再利用素材 | 文書を書くときにそのまま使える材料 |

---

## 突き合わせの概要

| 項目 | 内容 |
|---|---|
| 突き合わせ日 | （例: 2026-08-31） |
| 答える問い | （例: Docker Compose を本番環境で使ってよいか） |
| 投げた道具 | （例: Claude Code 2.1.233、codex-cli 0.149.1、agy 1.1.22） |
| 回収できた調査パック | （例: 3件中2件。Antigravity は応答が空だった） |
| 利用目的 | （例: docs/docker-compose.md の材料にする） |

## 判定

> 多数決で決めない。独立した根拠の数で決める。

| 主張 | 判定 | 独立した根拠の数 | 根拠ID |
|---|---|---|---|
| （例: 単一ホストなら本番で使える） | （例: 確定） | （例: 2） | （例: pack-claude S-01、pack-codex S-03） |
| （例: 複数ホストへは向かない） | （例: 暫定） | （例: 1） | （例: pack-claude S-01 のみ） |
| （例: 再起動時に自動復帰する） | （例: 未確認） | （例: 0） | （例: なし） |

**判定に付ける語**

| 判定 | 付ける条件 |
|---|---|
| 確定 | 独立した根拠が2件以上あり、どの道具も反論しなかった |
| 暫定 | 根拠が1件だけである。または反論が残っている |
| 未確認 | どの道具も根拠を出せなかった |

## 主張別の突き合わせ表

> 道具ごとに節を分けない。主張を行にして、道具を列にする。

| 主張 | Claude Code | Codex | Antigravity | 根拠は独立か |
|---|---|---|---|---|
| （例: 単一ホストなら使える） | （例: 支持 S-01） | （例: 支持 S-03） | （例: 言及なし） | （例: 独立。出典の URL が違う） |
| （例: 起動は2秒台） | （例: 言及なし） | （例: 支持 S-04） | （例: 支持 S-02） | （例: **同じ記事。独立していない**） |

**「根拠は独立か」の列を空にしない。** 出典の URL を突き合わせ、同じなら独立していないと書く。

## 差し戻しの記録

> 投げ直した争点だけを書く。投げ直していない主張はここへ書かない。

| 争点 | 差し戻した相手 | 返ってきた変化 |
|---|---|---|
| （例: 複数ホストの可否） | （例: Codex） | （例: 結論を変えた。提供元の記述を読み、単一ホスト向けと認めた） |
| （例: 起動時間の数値） | （例: Antigravity） | （例: 結論を保った。測定環境が違うと述べた） |

## 残った穴

> 埋まらなかった問いを消さない。文書へ持ち込むときに読者へ伝える。

- （例: 日本語での運用事例が見つからなかった。英語の資料だけで判断している）
- （例: Antigravity から応答が返らず、3つ目の視点を得られていない）

## 再利用素材

| 項目 | 内容 |
|---|---|
| 想定読者 | （例: 本番環境の構成を決めるバックエンド開発者） |
| 中心の主張 | （例: 単一ホストなら使ってよい） |
| 使える数値 | （例: 起動にかかる時間 2.1 秒。ただし判定は暫定である） |
| 使える固有名詞 | （例: Docker Compose v2.29） |
| 図表の候補 | （例: 単一ホストと複数ホストの比較表） |
| 書くときの注意 | （例: 「暫定」と判定した主張には、根拠が1件である旨を本文へ書く） |
